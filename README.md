# Investments

Course materials for **Investments**, a core module of the MSc Finance programme at the
FHNW School of Business in Basel.

This repository holds the material students run: the Colab notebooks and the data they
load. Slides, exercise sheets and announcements are on Moodle.

## What is here

```
exercise_utils.py     shared helper functions used by every notebook
Exercise_01/
  data/               snapshotted data files
Exercise_02/
  ...
```

One folder per weekly exercise. Each contains a skeleton notebook — the starting point —
and, once the exercise has been discussed in class, a solution notebook. Solutions are
added week by week over the semester, so a folder without one simply has not been
discussed yet.

## Using the notebooks

In Google Colab, choose **File → Open notebook → GitHub** and enter `KroeTiA/Investments`.
Open the notebook you need, then **save a copy to your Drive** before changing anything —
what you open here is read-only.

Nothing has to be installed locally. The notebooks fetch the helper module and read their
data straight from this repository, so they run the same way on any machine.

## Data

All data files are fixed snapshots rather than live feeds, which keeps results
reproducible across the semester and avoids hitting a provider during class. Sources are
credited in the notebook that uses them; the long US historical return series come from
Aswath Damodaran's publicly available dataset.
